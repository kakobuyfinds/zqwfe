What to check before placing an iTaoBuy order

  1. Match the listing and variant. Save the CAFANS listing ID and the original seller URL when available. Check the exact color, size and option price on the seller page.
  2. Compare measurements. Use a garment that fits as a reference for chest width and length. For shoes, record your foot length and check whether the seller chart uses foot length or insole length.
  3. Review warehouse QC when available. Check the option label, measurements and visible condition. Ask for a specific angle or a ruler photo if the existing photos leave a question open.
  4. Compare quotes on the same basis. Record item price, domestic delivery, agent fees, international shipping and any applicable taxes. Compare estimated parcel costs using the same destination, weight and dimensions.

iTaoBuy spreadsheet FAQ

What is an iTaoBuy spreadsheet?

It is a product shortlist used to organize seller links, variants, prices and checks before buying through a shopping agent.

Do the table prices include delivery?

The amounts are CAFANS reference item prices. Check the seller price and obtain a separate shipping quote for your parcel and destination.

Where do the two main buttons go?

Both open the CAFANS homepage. Product links in the table open their individual CAFANS listings.
